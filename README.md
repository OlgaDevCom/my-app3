## Running it

```bash
bash scripts/bootstrap.sh
flutter test
flutter run
```

The repository includes the selected Android/iOS native projects. The bootstrap
script resolves dependencies, generates localization and Dart code, and creates
only the generated Flutter files that are intentionally ignored. It applies the
requested minimum OS versions to the checked-in native projects without
overwriting later native customizations.

The AppGen verify workflow checks formatting, analysis, tests and a native
build for every selected platform. When Screen Gen is enabled, manually
dispatched verify runs also capture the default locale on a representative
phone per selected platform; download the screenshots from the run's artifacts.
It uses the Flutter SDK version recorded in the AppGen catalog.

## Building for Android and iOS

The workflows under `.github/workflows/` are the ones the ASO platform
dispatches. They declare exactly the inputs it sends — `version_string`,
`build_number` and `aso_dispatch_id` — so this repository can be linked to an
app on its GitHub page without editing anything.

## Before the first release build

AppGen cannot do these for you, and deliberately never holds the secrets involved:

- Add the iOS signing certificate, provisioning profile and App Store Connect API key as repository secrets.
- Add the Android keystore and its passwords as repository secrets.
